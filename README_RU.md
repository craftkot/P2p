# OpenTogether 0.3.0-alpha — Forge 1.20.1

Самостоятельный мод для приглашений Minecraft Java, без Essential, World Host и Steam как обязательных зависимостей.

## Что реализовано

- Меню «Друзья / Подключиться»: ввод приглашения.
- В меню паузы одиночного мира: кнопка «Пригласить друга».
- Cloudflare Worker + Durable Object: генерация 8-символьного кода, время действия 10 минут, получение TCP-адреса.
- Ограничения API (12 созданий в час и 90 проверок в минуту на IP); запрет LAN, CGNAT и зарезервированных IPv4-адресов.
- Логирование HTTP-статусов и исключений клиента Minecraft в `logs/latest.log`.
- Автоматические Node-тесты для срока действия, неверных адресов и лимитов API.

## Чего пока нет

**P2P/NAT traversal и ретранслятор не реализованы.** Другая сторона сможет зайти только к хосту с реально доступным TCP-адресом и открытым портом. Нет загрузки списка друзей из Mojang и отправки приглашений по нику. Cloudflare Worker ещё нужно развернуть самостоятельно. Выделенный Forge-сервер загрузил мод успешно; GUI клиента проверяется отдельным тестом. Не публикуйте API для широкой аудитории: антиабьюз упрощённый.

## Сборка

GitHub Actions: `.github/workflows/build.yml`. Альтернативный CI: `.circleci/config.yml`.

**Сборка JAR успешно прошла**: https://github.com/craftkot/P2p/actions — открой последний успешный запуск `Build OpenTogether`, скачай `opentogether-build`, внутри будет `opentogether-forge-1.20.1-0.3.0-alpha.jar`. Чтобы установить мод, помести JAR в папку `mods` профиля Minecraft 1.20.1 Forge 47.x. Старый JAR `OpenTogether Diagnostics` удалите из `mods`, если установлен.

**Серверный smoke-test успешен**: https://github.com/craftkot/P2p/actions/runs/40525508362. Сервер стартовал, Forge обнаружил и загрузил `opentogether` версии `0.2.0-alpha`. GUI клиента ещё требует ручной проверки.

## Cloudflare

1. Создать аккаунт Cloudflare.
2. В папке `cloudflare` выполнить `npm install`, `npx wrangler login`, `npm run deploy`.
3. Проверить `https://<worker>.workers.dev/health` — ожидается JSON с `ok: true`.
4. В Minecraft открой «Друзья / Подключиться» → «Настроить Cloudflare» и сохрани публичный HTTPS-адрес Worker. Он хранится в `config/opentogether.properties` (альтернатива: JVM-аргумент `-Dopentogether.api=...`).
5. В одиночном мире нажми «Пригласить друга» → «Открыть мир для LAN» (если мир ещё закрыт). Затем вернись к приглашению; мод покажет LAN-порт. Обеспечь доступность TCP-порта из интернета; в поле вводи **публичный** адрес хоста с портом.

Код приглашения — не секрет достаточной силы для публичного сервиса без дополнительной аутентификации. Для следующей версии запланированы одноразовые права доступа и проверка хоста.

## Важные исправления 0.3.0-alpha

- Запоздавший ответ Cloudflare не может подключить игрока после закрытия экрана.
- Кнопка отправки блокируется, пока выполняется запрос; ошибки API отображаются понятным языком.
- Появилась настройка HTTPS-адреса Worker внутри игры, без редактирования параметров JVM.
- Исправлены сбои обработки UDP-пакетов STUN и тайм-аут.
- Добавлены проверки нормализации кода приглашения и фильтрация непубличных адресов Cloudflare.
- CI проверяет Java-тесты, Worker, сборку Forge и загрузку выделенного сервера; отдельный клиентский smoke-тест запускает игру через Xvfb.

## Обновления STUN и сборки

- Добавлена кнопка «Проверить доступность STUN / UDP», которая отправляет STUN Binding Request по UDP и оценивает задержку. **Это диагностика, а не установка соединения с другим игроком**.
- STUN-парсер проверяет magic cookie, идентификатор транзакции и корректность IPv4 XOR-MAPPED-ADDRESS; внешний адрес из ответа не записывается в логи.
- Локальный тест Java: `javac --release 17 -d out src/main/java/dev/opentogether/StunProbe.java src/test/java/dev/opentogether/StunProbeTest.java`, затем `java -cp out dev.opentogether.StunProbeTest`.
- Локальная сборка на Windows: `powershell -NoProfile -ExecutionPolicy Bypass -File .\\build-local.ps1`. Потребуются JDK 17 и доступ к Maven Forge для загрузки зависимостей. Скрипт скачивает официальный Gradle 8.1.1 и выполняет `clean build`. Результат, если сборка успешна: `build/libs`.
- **Сборка JAR и загрузка на выделенном сервере подтверждены через GitHub Actions.** Клиентский GUI, создание приглашения в живом мире и подключение другого игрока пока не протестированы. Предыдущий JAR диагностики 0.1.0 имел несовместимость Forge — не используйте его.
