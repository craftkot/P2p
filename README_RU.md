# OpenTogether alpha 0.2.0 (Forge 1.20.1)

Собственный экспериментальный мод. В меню мультиплеера появляется кнопка «Друзья / Подключиться», в меню паузы одиночного мира — «Пригласить друга».

## Важно
Это **не готовый P2P**. Код приглашения через Cloudflare содержит публично доступный TCP-адрес. Для соединения из интернета нужен доступный порт. Автоматический NAT traversal, ретранслятор и получение списка друзей ещё не реализованы. Никогда не публикуйте личный IP без необходимости.

## Сборка
GitHub Actions запускает ForgeGradle под Java 17. JAR доступен в артефактах workflow, только если компиляция прошла успешно.

## Cloudflare
Перейти в `cloudflare/`, выполнить `npm install`, `npx wrangler login`, `npm run deploy`. Понадобится собственный Cloudflare-аккаунт и разрешение на публикацию Worker.

В параметрах JVM лаунчера указывать `-Dopentogether.api=https://<адрес>.workers.dev`. Не включайте URL с секретами.

Логи ошибок доступны в `logs/latest.log`. Первый запуск должен проходить без старого OpenTogether Diagnostics.

## Безопасность
API пока не имеет ограничения частоты, авторизации клиентов и безопасного протокола согласования. Он пригоден только для локальных экспериментов, не для публичного сервиса.
