# OpenTogether 0.5.0-alpha — один JAR для Forge 1.20.1

**Для игры с друзьями через интернет нужен только один файл:** `opentogether-forge-1.20.1-0.5.0-alpha-all.jar`.

Внутри OpenTogether находится **e4mc 6.2.3** (Forge Jar-in-Jar). Это официальный исходный сетевой движок e4mc, лицензия MIT, автор Skye, его оригинальные классы и протокол не маскируются под наш код. Лицензия приложена в `licenses/e4mc-MIT.txt`. Соединение идёт через публичный сервис e4mc; он может оказаться недоступным, в том числе из-за ограничений сети.

## Установка

1. Установи Forge 47.x для Minecraft Java 1.20.1 и Java 17.
2. **Удали** старые JAR OpenTogether и отдельно установленный e4mc из папки `mods`.
3. Скачай последний **успешный** артефакт `opentogether-onejar-forge-1.20.1` во вкладке [GitHub Actions](https://github.com/craftkot/P2p/actions). Используй только JAR, название которого заканчивается `-all.jar`; обычный `opentogether-...jar` не включает сетевой компонент.
4. Положи этот один JAR в `mods` и запусти Minecraft.

Никаких Cloudflare Worker, регистрации в Steam, платных серверов, отдельного e4mc или проброса портов обычно не требуется.

## Как пригласить

1. Открой одиночный мир.
2. Нажми Esc → «Пригласить друга» → «Открыть мир для сети (LAN)».
3. Дождись, пока e4mc напишет в чат публичный адрес формата `название.регион.e4mc.link`.
4. Скопируй адрес из чата и отправь другу.

Друг может играть через обычное Minecraft → «Сетевая игра» или OpenTogether → «Подключиться к другу». Версии Minecraft и игровых модов должны совпадать.

## Проверки и ограничения

- GitHub Actions собирает единый JAR, проверяет вложенный JAR e4mc и сохранение лицензии.
- Экспериментальный тест установки **одного JAR** в официальный выделенный Forge 1.20.1 успешно загрузил оба мода, связался с брокером e4mc и получил публичный адрес. Это доказывает работу упаковки и сетевой инициализации.
- **Клиентская кнопка в Minecraft и реальное присоединение второго игрока с другого компьютера ещё не подтверждены.**
- e4mc сохраняет контроль над своими ретрансляторами; их доступность и задержка не гарантированы.
- Это не полностью независимая собственная сеть OpenTogether и не стандартное TCP-подключение без сервиса.
- Код модового меню открыт в `src/main/java/dev/opentogether`; кодовая база прежнего Cloudflare Worker в `cloudflare/` не используется в этой версии.
