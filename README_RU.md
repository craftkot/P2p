# OpenTogether — экспериментальная alpha (Forge 1.20.1)

Самостоятельный мод для приглашений Minecraft Java, без Essential, World Host и Steam как обязательных зависимостей.

## Что реализовано

- Меню «Друзья / Подключиться»: ввод приглашения.
- В меню паузы одиночного мира: кнопка «Пригласить друга».
- Cloudflare Worker + Durable Object: генерация 8-символьного кода, время действия 10 минут, получение TCP-адреса.
- Простейшая защита от частых запросов по IP (12 созданий в час и 90 проверок в минуту), отказ от локальных IPv4-адресов.
- Логирование HTTP-статусов и исключений клиента Minecraft в `logs/latest.log`.
- Автоматические Node-тесты для срока действия, неверных адресов и лимитов API.

## Чего пока нет

**P2P/NAT traversal и ретранслятор не реализованы.** Другая сторона сможет зайти только к хосту с реально доступным TCP-адресом и открытым портом. Нет загрузки списка друзей из Mojang и отправки приглашений по нику. Cloudflare Worker не развёрнут. GUI и мод ещё не проверены реальным запуском Minecraft. Не публикуйте API для широкой аудитории: антиабьюз упрощённый.

## Сборка

GitHub Actions: `.github/workflows/build.yml`. Альтернативный CI: `.circleci/config.yml`. Приватный GitHub Actions runner сейчас не запускает задания, поэтому **готового проверенного JAR пока нет**.

## Cloudflare

1. Создать аккаунт Cloudflare.
2. В папке `cloudflare` выполнить `npm install`, `npx wrangler login`, `npm run deploy`.
3. Проверить `https://<worker>.workers.dev/health` — ожидается JSON с `ok: true`.
4. Добавить JVM-аргумент Minecraft `-Dopentogether.api=https://<worker>.workers.dev`.
5. Открыть одиночный мир через «Открыть для сети» (LAN) и обеспечить доступность его TCP-порта из интернета; в GUI приглашений вводить **публичный** хост:порт.

Код приглашения — не секрет достаточной силы для публичного сервиса без дополнительной аутентификации. Для следующей версии запланированы одноразовые права доступа и проверка хоста.

## Логи

`logs/latest.log`: ищи `[OpenTogether]`. Публикуя логи, удали адреса, коды, токены, если они присутствуют.
