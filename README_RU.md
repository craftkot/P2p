# OpenTogether 0.4.0-alpha — Forge 1.20.1

## Игра с друзьями без Cloudflare

Настройка Cloudflare, адрес Worker и пригласительные коды удалены из клиента. Теперь для подключения используется обычный адрес Minecraft. Для бесплатного внешнего доступа рекомендуем открытый мод **e4mc** — его существующую сеть ретрансляторов, без своего сервера и проброса портов.

**Важно:** OpenTogether 0.4.0 — облегчённый интерфейс для друзей, не самостоятельная реализация P2P. e4mc — отдельная зависимость **только у хозяина мира**, чтобы играть через интернет без открытых портов. Друзья подключаются обычным клиентом Minecraft 1.20.1. Используются серверы разработчиков e4mc, доступность которых не гарантирована.

## Что установить хозяину мира

1. Minecraft Java 1.20.1 + Forge 47.x.
2. OpenTogether 0.4.0-alpha (JAR из успешной GitHub-сборки).
3. [e4mc 6.2.3 Forge](https://modrinth.com/mod/e4mc/version/6.2.3-forge) — совместим с Minecraft 1.20.1, нужен для игры через интернет без проброса портов.

Положить оба JAR в `mods`, перезапустить Minecraft. Отдельный аккаунт Cloudflare/Steam, VPN и проброс портов не нужны. Оба мода не имеют отношения к официальному сервису Mojang. Доверяй полученному адресу и не делись им с незнакомцами.

## Пригласить

1. Зайти в свой одиночный мир и нажать Esc → **Пригласить друга**.
2. Нажать **Открыть мир для сети (LAN)**, если он не открыт.
3. После публикации e4mc должен показать в игровом чате публичный адрес, обычно с окончанием `.e4mc.link`.
4. Щёлкнуть адрес в чате, чтобы скопировать (это возможность e4mc), и отправить его другу.

Игрок без e4mc может открыть мир для обычной локальной сети; интернет-соединение через NAT при этом не появится.

## Подключиться

Открыть главное меню или «Сетевая игра», нажать **Подключиться к другу**. Вставить публичный адрес от e4mc (например, `something.e4mc.link`) и нажать «Подключиться к другу». Если друг запустил модифицированный мир, игровые моды и версии должны совпадать.

## Проверки

CI: `.github/workflows/build.yml` проверяет сборку Forge и отдельные тесты; `.github/workflows/server-smoke.yml` запускает выделенный сервер; `.github/workflows/client-smoke.yml` пробует запустить клиент в виртуальном экране. Тест подключения двух игроков через настоящий e4mc ещё не проведён.

## Оставшиеся ограничения

- Приглашение по нику и встроенный список друзей ещё не реализованы.
- Автоподключение по коду не поддерживается: вместо кода передаётся готовый адрес e4mc.
- Реальные скорость/пинг зависят от маршрута до ретранслятора и производительности компьютера хозяина.
- Поддержка самого протокола e4mc внутри OpenTogether пока не реализована: нужен официальный мод e4mc на стороне хозяина.
- `cloudflare/` оставлена только в исходниках на будущее, текущий JAR к Cloudflare не обращается.
- Для диагностики неполадок: `logs/latest.log`.
