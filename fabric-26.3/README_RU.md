# OpenTogether — Minecraft 26.3 Fabric (экспериментальный порт)

Отдельный проект в папке `fabric-26.3`. Он не заменяет Forge 1.20.1, требует Java 25 и Fabric Loader 0.20.1.

- Внутри сборки e4mc 6.2.3-fabric-modern для LAN-туннеля без проброса портов.
- Fabric API 0.165.0+26.3 включается как вложенная зависимость; если Fabric Loader не обнаруживает API, нужна отдельная установка.
- Для публикации мира используется официальный сервис e4mc. Доступность и задержки не гарантированы.
- Порт клиента и соединение двух игроков нужно протестировать; CI-компиляция не доказывает их работоспособности.

Сборка: Gradle 9.6, Java 25, команда `gradle build` из `fabric-26.3`.

## Диагностика сети (Fabric 26.3)

Открой мир, затем **Пауза → OpenTogether → Диагностика**. В меню доступны:
- счётчик событий загрузки клиентских чанков за последние 10 секунд;
- количество закешированных чанков, дальность прорисовки, время с последней загрузки;
- пинг Minecraft у подключившегося игрока либо среднее время тика встроенного сервера у хоста;
- кнопка копирования текстового отчёта.

Для сравнения попроси обоих игроков открыть диагностику и пройти одинаковое расстояние по уже загруженному миру. Сопоставляй показатели хоста и гостя. **Ноль загрузок при стоянии на месте не означает зависание.** Счётчик не измеряет скорость сети и не разделяет генерацию, отправку и обработку чанков.

Надпись `e4mc` не доказывает прямой маршрут: direct и relay не всегда можно надёжно различить по адресу соединения. Высокая задержка сама по себе не говорит о нехватке CPU или RAM; измеряй отдельно пинг, время тика и поведение при перемещении. Мод пока не меняет алгоритмы генерации или отправки чанков — без серверных замеров это могло бы ухудшить производительность.
