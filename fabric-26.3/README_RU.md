# OpenTogether — Minecraft 26.3 Fabric (экспериментальный порт)

Отдельный проект в папке `fabric-26.3`. Он не заменяет Forge 1.20.1, требует Java 25 и Fabric Loader 0.20.1.

- Внутри сборки e4mc 6.2.3-fabric-modern для LAN-туннеля без проброса портов.
- Fabric API 0.165.0+26.3 включается как вложенная зависимость; если Fabric Loader не обнаруживает API, нужна отдельная установка.
- Для публикации мира используется официальный сервис e4mc. Доступность и задержки не гарантированы.
- Порт клиента и соединение двух игроков нужно протестировать; CI-компиляция не доказывает их работоспособности.

Сборка: Gradle 9.6, Java 25, команда `gradle build` из `fabric-26.3`.
